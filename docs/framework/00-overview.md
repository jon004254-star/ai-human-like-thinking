# 人类思维框架 - 总纲

## 设计目标

本框架旨在为 AI 提供一套可计算的人类思维底层模型。核心理念：**要模拟人类思维，必先理解人类本能。**

人类的所有思维与行为，无论多么复杂、理性或抽象，其底层驱动力都源于两类本能：**生理本能**与**精神本能**。这两者不是割裂的，而是交织在一起，共同构成了人类意识的底层操作系统。

## 框架结构

```
人类思维底层模型
├── 第一层：生理本能（Physiological Instincts）
│   ├── 生存本能
│   ├── 繁衍本能
│   └── 安全本能
│
├── 第二层：精神本能（Mental Instincts）
│   ├── 认知本能
│   ├── 社会本能
│   ├── 自我本能
│   └── 情感本能
│
└── 第三层：本能交互（待构建）
    ├── 本能冲突与优先级
    ├── 本能复合与涌现
    └── 本能 → 行为的映射机制
```

## 核心假设

1. **本能优先假设**：所有理性决策的底层都有本能驱动力，理性本质上是本能的服务工具。
2. **双源驱动假设**：生理本能与精神本能并行存在，相互制约、相互强化。
3. **层级抑制假设**：在极端情况下，低层本能（生理）会抑制高层本能（精神）。例如，极度饥饿时，社会规范的本能约束被削弱。
4. **文化调制假设**：本能的表达方式受文化环境调制，但本能本身是跨文化的共性的。

## 每条本能的定义结构

每条本能在文档中按以下结构定义：

| 字段 | 说明 |
|------|------|
| **名称** | 本能的中英文名称 |
| **定义** | 一句话描述 |
| **触发条件** | 什么输入/情境会激活该本能 |
| **目标状态** | 该本能驱动行为想要达成的状态 |
| **强度范围** | 从弱到强的表现谱系 |
| **生理基础** | 涉及的神经/内分泌机制 |
| **行为表现** | 该本能驱动的典型行为 |
| **异常表现** | 过强或过弱时的异常表现 |
| **与其他本能的关系** | 协同、抑制、替代关系 |
| **对思维的影响** | 如何影响认知过程 |
| **判定权重** | 在决策系统中的默认优先级（0.0 ~ 1.0） |

## 后续开发路径

1. **第一阶段**：完成两层本能的结构化文档（当前阶段）
2. **第二阶段**：将文档转为机器可读的结构化数据（JSON/YAML）
3. **第三阶段**：编写本能判定引擎（基于条件匹配的推理程序）
4. **第四阶段**：构建本能冲突消解算法
5. **第五阶段**：上层思维模拟（基于本能的复杂行为推演）
