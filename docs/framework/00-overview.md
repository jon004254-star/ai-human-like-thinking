# 人类思维框架 - 总纲

## 设计目标

本框架旨在为 AI 提供一套可计算的人类思维底层模型。核心理念：**要模拟人类思维，必先理解人类本能。** 但理解本能的目的不是让 AI 像动物一样按本能行动——恰恰相反，是为了让 AI 理解：**人类成年后的绝大多数行为，是在社会规则压制本能之后的产物。本能只是在特定条件下才裸露出来的底层信号。**

## 核心模型：本能-社会双层结构

```
人类行为决策 = 本能信号 × 社会调制系数 + 理性计算

其中：
  - 本能信号：来自生理本能和精神本能的基础驱动力（本框架定义的 30 条本能）
  - 社会调制系数：文化、规范、教育、法律对本能的压制/引导因子（0.0 ~ 1.0）
    - 正常成年人日常场景：调制系数 0.05 ~ 0.15（本能被深度压制）
    - 极端情境（生命威胁/极度疲劳/情绪劫持）：调制系数 0.60 ~ 0.95（本能裸露）
  - 理性计算：前额叶主导的目标导向推理（在成年人行为中占主导地位）
```

这个模型的核心假设是：**AI 在判读人类行为时，不应该过度依赖本能解释。** 一个正常人拒绝分享食物，不是因为他"饿"，而是因为社会规则告诉他所有权和边界。只有在极端饥饿时，本能才会撕破社会规则的面纱。

## 本能何时"裸露"？——触发条件分类

| 触发类型 | 说明 | 本能权重提升幅度 | 示例 |
|----------|------|------------------|------|
| **生理剥夺** | 基本生理需求长期未满足 | ↑↑↑ | 极度饥饿、睡眠剥夺、窒息 |
| **急性威胁** | 突然出现的生命/安全威胁 | ↑↑↑ | 地震、攻击、车祸前瞬间 |
| **情绪劫持** | 强烈情绪压倒前额叶控制 | ↑↑ | 暴怒、极度恐惧、狂喜 |
| **群体情境** | 去个体化、匿名性、从众压力 | ↑↑ | 暴乱、网络暴力、群体狂欢 |
| **疲劳/资源耗竭** | 自我控制资源耗尽 | ↑ | 长期压力后、深夜、酒后 |
| **早期发育/衰老** | 前额叶未成熟或退化 | ↑↑ | 儿童、青少年、老年痴呆 |
| **精神障碍** | 特定脑区功能异常 | ↑↑↑ | 精神病态、冲动控制障碍 |

> **设计启示**：AI 判定系统中，正常情境下每条本能的判定权重应默认取低值（0.05 ~ 0.20）。只有当触发条件满足时，才提升对应本能的权重。这个机制本身就是"理解人类情境"的关键。

## 核心假设

1. **本能优先假设（弱版本）**：所有理性决策的底层都有本能驱动力，但理性在常态下是本能的服务工具而非奴隶。——参考 Damasio《笛卡尔的错误》
2. **双层驱动假设**：生理本能与精神本能并行存在，相互制约、相互强化。——参考 Maslow 需求层次、Panksepp 情感神经科学
3. **层级抑制假设**：在极端情况下，低层本能（生理）会抑制高层本能（精神）。但在常态下，高层（社会规范）可以且确实在抑制低层（本能）。——参考 Freud 的超我/本我冲突、Baumeister 自我控制理论
4. **社会调制假设**：本能的表达方式受文化环境调制，但本能本身的神经基础是跨文化共性的。——参考 Pinker《白板论》、Henrich 的 WEIRD 心理学批判
5. **情境依赖性假设（新增）**：本能的"裸露度"高度依赖情境。同一个人，在法庭上是理性公民，在灾难中可能是求生动物。AI 判定必须基于情境变量做权重动态调整。——参考 Zimbardo 情境主义、Milgram 服从实验
6. **权重动态假设（新增）**：每条本能在 AI 判定系统中的权重不是常量，而是情境变量（生理状态、社会环境、情绪强度、认知负荷）的函数。**静态权重仅在情境缺失时作为默认值使用。**

## 每条本能的定义结构

| 字段 | 说明 |
|------|------|
| **名称** | 本能的中英文名称 |
| **定义** | 一句话描述该本能的核心机制 |
| **触发条件** | 什么输入/情境会激活该本能 |
| **目标状态** | 该本能驱动行为想要达成的状态 |
| **强度谱系** | 从弱到强的表现连续谱 |
| **生理/神经基础** | 涉及的脑区、神经递质、激素、神经回路 |
| **行为表现** | 该本能驱动的典型行为模式 |
| **异常表现** | 过强或过弱时的病理表现 |
| **社会压制机制** | **（新增）** 社会规范、文化、教育如何压制/调制该本能 |
| **裸露条件** | **（新增）** 什么具体情境会突破社会压制、让该本能裸露出来 |
| **与其他本能的关系** | 协同、抑制、替代关系 |
| **对思维的影响** | 如何影响认知过程（注意偏向、记忆编码、风险偏好等） |
| **核心研究引用** | **（新增）** 支撑该本能定义的关键学术著作和研究 |
| **常态判定权重** | 在正常成年人日常决策中的默认权重（0.0 ~ 1.0） |
| **裸露态判定权重** | 在触发条件满足时的最大权重（0.0 ~ 1.0） |

## 本能判定权重的双层设计

每条本能现在有两个权重值：

| 权重类型 | 适用场景 | 典型范围 | 含义 |
|----------|----------|----------|------|
| **常态权重** | 成年人，日常社交/工作情境，无极端生理/情绪状态 | 0.02 ~ 0.20 | 本能被深度压制，只是微弱的背景信号 |
| **裸露态权重** | 生命威胁、极度生理剥夺、急性情绪劫持、去个体化群体 | 0.60 ~ 1.00 | 社会规则失效，本能直接驱动行为 |

**权重设计原则**：
- 呼吸、窒息防御等直接关系到存亡的本能，即使常态也有较高的生理自主权，但其对**社会行为**的影响权重仍然低
- 社会本能（归属、地位等）在常态下比生理本能（饥饿、性等）对**社会行为**的影响权重更高——因为社会规范本身就包含这些本能
- 情感本能是"中间层"：常态下被压制，但比生理本能更容易被触发裸露
