# 第一层：生理本能

> 生理本能是所有人类行为的最底层驱动力。它们由进化塑造，通过神经递质和激素系统调控，在个体层面确保生存与繁衍。生理本能的特点是：**不可消除、只能暂时满足或被抑制、在极端状态下会覆盖精神本能。**

---

## 一、生存本能

生存本能是最优先的生理驱动，直接关系到个体存亡。

### 1.1 饥饿（Hunger）

| 字段 | 内容 |
|------|------|
| **定义** | 由能量缺乏触发的觅食与进食驱动力 |
| **触发条件** | 血糖水平下降、胃饥饿素（Ghrelin）分泌、视觉/嗅觉暴露于食物线索 |
| **目标状态** | 摄入足够能量，恢复能量平衡 |
| **强度范围** | 轻微饥饿（想吃）→ 中度饥饿（注意力分散）→ 极度饥饿（无法思考其他事）→ 饥荒状态（道德判断扭曲） |
| **生理基础** | 下丘脑弓状核（ARC）、胃饥饿素、瘦素（Leptin）、胰岛素 |
| **行为表现** | 觅食、进食、囤积食物、对食物线索高度敏感 |
| **异常表现** | 过强：暴食症、食物成瘾；过弱：厌食症、饥饿感知丧失 |
| **与其他本能的关系** | 抑制睡眠本能（饿得睡不着）；与安全本能冲突（冒险觅食）；在社会情境中受归属本能调制（分享食物） |
| **对思维的影响** | 饥饿时注意力偏向食物相关刺激；延迟满足能力下降；风险偏好改变；道德判断更宽容 |
| **判定权重** | 0.95（最高优先级之一） |

### 1.2 渴（Thirst）

| 字段 | 内容 |
|------|------|
| **定义** | 由体液渗透压升高触发的饮水驱动力 |
| **触发条件** | 血浆渗透压升高、血容量减少、口腔干燥 |
| **目标状态** | 补充水分，恢复体液平衡 |
| **强度范围** | 口干（舒适饮水）→ 中度渴（持续想喝）→ 极度渴（无法思考其他） |
| **生理基础** | 下丘脑室旁核（PVN）、抗利尿激素（ADH）、肾素-血管紧张素系统 |
| **行为表现** | 寻找水源、饮水、对液体线索敏感 |
| **异常表现** | 过强：烦渴症（如糖尿病）；过弱：脱水风险 |
| **与其他本能的关系** | 与饥饿本能共享觅食行为；极度缺水时优先级与饥饿接近 |
| **对思维的影响** | 轻度脱水即影响认知表现、注意力和短期记忆 |
| **判定权重** | 0.90 |

### 1.3 睡眠（Sleep）

| 字段 | 内容 |
|------|------|
| **定义** | 由昼夜节律和睡眠压力触发的周期性休息驱动力 |
| **触发条件** | 腺苷积累、褪黑素分泌、昼夜节律信号（视交叉上核） |
| **目标状态** | 进入睡眠状态，完成神经修复和记忆巩固 |
| **强度范围** | 困倦（效率下降）→ 中度疲劳（微睡眠）→ 极度困乏（幻觉风险） |
| **生理基础** | 视交叉上核（SCN）、腺苷系统、褪黑素、GABA能系统 |
| **行为表现** | 寻找安全休息场所、闭眼、躺下、进入睡眠 |
| **异常表现** | 过强：嗜睡症；过弱：失眠、睡眠剥夺导致的精神症状 |
| **与其他本能的关系** | 睡眠不足会放大饥饿感、削弱恐惧调节、降低社会判断力 |
| **对思维的影响** | 睡眠不足严重损害判断力、创造力、情绪调节和执行功能 |
| **判定权重** | 0.85 |

### 1.4 呼吸（Breathing）

| 字段 | 内容 |
|------|------|
| **定义** | 维持氧气-二氧化碳平衡的自动/半自主驱动力 |
| **触发条件** | 血氧下降、二氧化碳升高（延髓化学感受器） |
| **目标状态** | 维持正常血氧饱和度 |
| **强度范围** | 正常（无意识）→ 呼吸困难（有意识关注）→ 窒息（全力求生） |
| **生理基础** | 延髓呼吸中枢、颈动脉体化学感受器、膈神经 |
| **行为表现** | 自主呼吸、憋气后的强制吸气、窒息时的剧烈挣扎 |
| **异常表现** | 过强：过度换气综合征；受阻：睡眠呼吸暂停 |
| **与其他本能的关系** | 窒息恐慌压倒所有其他本能；呼吸与恐惧本能深度绑定 |
| **对思维的影响** | 呼吸受阻时思维完全被求生占据；深呼吸可调节情绪状态 |
| **判定权重** | 1.00（最高优先级，不可被覆盖） |

### 1.5 体温调节（Thermoregulation）

| 字段 | 内容 |
|------|------|
| **定义** | 维持核心体温在 36.5-37.5°C 范围内的驱动力 |
| **触发条件** | 皮肤温度感受器信号、核心温度偏离设定点 |
| **目标状态** | 恢复热平衡 |
| **强度范围** | 轻微不适（加减衣物）→ 中度（发抖/出汗）→ 极端（失温/中暑） |
| **生理基础** | 下丘脑视前区（POA）、皮肤温度感受器、棕色脂肪、骨骼肌（发抖） |
| **行为表现** | 加减衣物、寻找阴凉/温暖处、蜷缩、发抖、出汗 |
| **异常表现** | 过强：中暑、恶性高热；过弱：失温症 |
| **与其他本能的关系** | 极端温度下抑制社会本能（如在灾难中抢夺保暖资源） |
| **对思维的影响** | 过热/过冷显著降低认知能力；舒适温度促进高效思考 |
| **判定权重** | 0.80（常态）→ 0.98（极端温度） |

### 1.6 疼痛回避（Pain Avoidance）

| 字段 | 内容 |
|------|------|
| **定义** | 由组织损伤或潜在损伤信号触发的回避/逃离驱动力 |
| **触发条件** | 伤害感受器激活（机械、温度、化学刺激超过阈值） |
| **目标状态** | 停止或远离伤害源，启动保护和修复 |
| **强度范围** | 不适（可忽略）→ 疼痛（分心）→ 剧痛（无法思考）→ 极度疼痛（意识改变） |
| **生理基础** | 伤害感受器（Aδ纤维、C纤维）、脊髓背角、前扣带皮层、岛叶 |
| **行为表现** | 缩回反射、逃离、保护受伤部位、寻求止痛 |
| **异常表现** | 过强：痛觉过敏、慢性疼痛综合征；缺失：先天性无痛症（极度危险） |
| **与其他本能的关系** | 剧烈疼痛压倒几乎所有其他本能；慢性疼痛持续消耗精神资源 |
| **对思维的影响** | 疼痛占据注意力通道；慢性疼痛导致抑郁和决策能力下降 |
| **判定权重** | 疼痛强度映射：0.60（轻度）→ 0.95（重度）|

### 1.7 排泄（Excretion）

| 字段 | 内容 |
|------|------|
| **定义** | 排出代谢废物的生理驱动力 |
| **触发条件** | 膀胱/直肠膨胀信号 |
| **目标状态** | 排泄完成，恢复舒适状态 |
| **强度范围** | 轻微便意 → 明显需排泄 → 极度紧迫 |
| **生理基础** | 膀胱/直肠牵张感受器、骶髓反射、大脑皮层抑制控制 |
| **行为表现** | 寻找排泄场所、排泄行为 |
| **异常表现** | 失禁（控制丧失）；排泄恐惧（社会情境下的过度抑制） |
| **与其他本能的关系** | 受社会本能强抑制（排泄需要私密空间）；极端紧迫时突破社会抑制 |
| **对思维的影响** | 紧迫时占据注意力；排泄控制涉及社会认知发展 |
| **判定权重** | 0.50（常态可控）→ 0.80（极度紧迫） |

## 二、繁衍本能

繁衍本能确保基因延续，是人性的核心驱动力之一。

### 2.1 性欲（Sexual Drive）

| 字段 | 内容 |
|------|------|
| **定义** | 由性激素和感官刺激触发的性行为驱动力 |
| **触发条件** | 性激素水平（睾酮/雌激素）、感官刺激（视觉/触觉/嗅觉）、性幻想 |
| **目标状态** | 性满足（伴随多巴胺和催产素释放） |
| **强度范围** | 微弱（潜在的）→ 中等（主动关注）→ 强烈（占据思维）→ 成瘾（失控） |
| **生理基础** | 下丘脑、杏仁核、性激素、多巴胺奖赏通路 |
| **行为表现** | 求偶行为、性吸引、性行为、性竞争 |
| **异常表现** | 过强：性成瘾；过弱：性欲低下障碍；偏差：性欲倒错 |
| **与其他本能的关系** | 可暂时抑制睡眠和饥饿（如情侣彻夜相处不思饮食）；受社会本能调制（道德约束、社会规范） |
| **对思维的影响** | 性唤起时风险承担增加；对潜在伴侣的判断更宽容；影响注意力和资源分配 |
| **判定权重** | 0.70 |

### 2.2 护幼本能（Parental Care）

| 字段 | 内容 |
|------|------|
| **定义** | 保护和抚育后代的驱动力 |
| **触发条件** | 与后代（特别是婴儿）的接触、婴儿的特征信号（大眼睛、哭声、婴儿气味）、催产素 |
| **目标状态** | 后代安全、健康成长 |
| **强度范围** | 普通关怀 → 主动保护 → 自我牺牲 |
| **生理基础** | 催产素系统、伏隔核奖赏通路、前额叶皮层 |
| **行为表现** | 喂养、保护、教导、牺牲自身利益保障后代 |
| **异常表现** | 过弱：忽视/虐待儿童；产后抑郁导致的本能抑制 |
| **与其他本能的关系** | 与恐惧本能协同（保护后代免受威胁）；可压倒自我保全本能（父母为子女牺牲）；与归属本能交织（家庭纽带） |
| **对思维的影响** | 对威胁的判断阈值降低（过度警惕）；资源分配优先偏向后代 |
| **判定权重** | 0.90（对自己孩子的场景） |

## 三、安全本能

安全本能是个体对威胁的检测与响应系统，是连接生理与精神本能的桥梁。

### 3.1 战斗或逃跑（Fight or Flight）

| 字段 | 内容 |
|------|------|
| **定义** | 面对感知到的威胁时，自动激活的应激反应驱动力 |
| **触发条件** | 威胁刺激（物理危险、攻击信号、突然的巨响、高度/封闭空间等） |
| **目标状态** | 消除威胁或脱离危险 |
| **强度范围** | 警觉 → 焦虑 → 恐惧 → 恐慌 → 僵直（无法动弹） |
| **生理基础** | 杏仁核、交感神经系统、肾上腺素/去甲肾上腺素、HPA轴（皮质醇） |
| **行为表现** | 战斗（反击）、逃跑（撤离）、僵直（冻结）、讨好（社会情境中的屈服） |
| **异常表现** | 过强：焦虑障碍、PTSD、恐慌症；过弱：风险寻求、缺乏危险感知 |
| **与其他本能的关系** | 压倒几乎所有其他本能（生存优先）；与疼痛回避深度协同 |
| **对思维的影响** | 恐惧时杏仁核劫持前额叶（理性思考被抑制）；注意力聚焦于威胁源；记忆编码增强（闪光灯记忆） |
| **判定权重** | 威胁强度映射：0.50（轻微威胁）→ 0.98（生命威胁） |

### 3.2 领域意识（Territoriality）

| 字段 | 内容 |
|------|------|
| **定义** | 占有和保卫个人空间/资源的驱动力 |
| **触发条件** | 对自有领域/资源的侵犯、陌生者接近个人空间 |
| **目标状态** | 恢复对领域的控制感和安全感 |
| **强度范围** | 轻微不适（陌生人太近）→ 防御反应 → 攻击性驱逐 |
| **生理基础** | 杏仁核、睾酮水平、个人空间相关的顶叶神经元 |
| **行为表现** | 划定个人空间、标记领域（如办公桌布置）、防御入侵、对"我的"物品的保护性 |
| **异常表现** | 过强：偏执型人格障碍；缺失：个人空间边界丧失 |
| **与其他本能的关系** | 受社会本能调制（文化决定个人空间大小）；与归属本能冲突（要亲近又要保持边界） |
| **对思维的影响** | 领域被侵犯时注意力和敌意升高；所有权的认知偏差（禀赋效应） |
| **判定权重** | 0.40 |

### 3.3 风险规避（Risk Aversion）

| 字段 | 内容 |
|------|------|
| **定义** | 避免不确定的负面结果的保守驱动力 |
| **触发条件** | 不确定性情境、潜在损失信号、过往负面经验 |
| **目标状态** | 减少不确定性，保护已有资源 |
| **强度范围** | 轻微谨慎 → 明显保守 → 完全规避 |
| **生理基础** | 前岛叶（风险评估）、杏仁核（损失敏感）、多巴胺系统（预期奖赏 vs 惩罚） |
| **行为表现** | 选择确定选项而非不确定选项、风险-收益权衡时的保守偏向、购买保险 |
| **异常表现** | 过强：广泛性焦虑、决策瘫痪；过弱：病理性赌博、冲动行为 |
| **与其他本能的关系** | 与恐惧本能共享神经回路；与好奇心本能（精神层）形成根本张力——安全 vs 探索 |
| **对思维的影响** | 损失厌恶（损失的心理痛苦是等额收益快乐的两倍）；维持现状偏差；过度关注负面可能性 |
| **判定权重** | 0.55 |

## 生理本能优先级总览

| 优先级 | 本能 | 权重 | 可被覆盖 |
|--------|------|------|----------|
| 1 | 呼吸 | 1.00 | 不可 |
| 2 | 疼痛回避（重度） | 0.95 | 几乎不可 |
| 3 | 饥饿（极度） | 0.95 | 几乎不可 |
| 4 | 战斗/逃跑（生命威胁） | 0.98 | 不可 |
| 5 | 渴（极度） | 0.90 | 几乎不可 |
| 6 | 护幼 | 0.90 | 很少 |
| 7 | 睡眠（极度） | 0.85 | 药物可短暂对抗 |
| 8 | 体温调节（极端） | 0.80→0.98 | 不可 |
| 9 | 性欲 | 0.70 | 可 |
| 10 | 排泄（紧迫） | 0.50→0.80 | 可短期抑制 |
| 11 | 风险规避 | 0.55 | 可 |
| 12 | 领域意识 | 0.40 | 经常可 |

注：权重值将在后续的判定引擎中用于计算本能冲突时的优先级。当多个本能同时激活时，高权重的本能会抑制低权重的本能表达。
